# jeLajaH

Android-first, consent-based browser task platform with a central controller, real-device Chrome, transparent task rewards, and auditable automation.

**Status:** Architecture / PRD baseline v1.0; not implemented. **P0 blocker:** prove Chrome Android CDP control on stock non-root devices without recurring external ADB dependency.

Start at [docs/PRD.md](docs/PRD.md), then [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md), [docs/ANDROID.md](docs/ANDROID.md), [docs/API_AND_DATA.md](docs/API_AND_DATA.md), [docs/SECURITY_AND_REWARDS.md](docs/SECURITY_AND_REWARDS.md), and [docs/DELIVERY_PLAN.md](docs/DELIVERY_PLAN.md).

This project is for authorized browsing/testing tasks. No fingerprint spoofing, stealth evasion, deceptive ad impressions/clicks, fake human traffic, or unconsented remote access.
